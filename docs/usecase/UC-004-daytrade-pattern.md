# UC-004 — 단타 모드: 당일 등락 패턴 분석·제안


| 항목 | 내용 |
|------|------|
| TraceID | UC-004 |

| 모드 | `MODE_DAY` |
| 우선순위 | P1 |

## 목적

사용자가 선택한 종목에 대해 **당일** 가격 시계열을 분석해 **저점 매수·고점 매도** 후보 구간을 제안한다. 자동 주문은 하지 않는다(기본).

## 사전 조건

- 장중 또는 당일 분봉/틱 데이터 가용(Tier A 분봉 TR 또는 Tier1 보조).
- UC-001 연결.

## 기본 흐름

1. Investor가 단타 모드 워크스페이스 진입.
2. 종목 선택(관심종목·검색).
3. `IntradayDataAggregator` 가 당일 시계열 로드·정규화.
4. `IntradayPatternAnalyzer` 실행:
   - 피크/밸리 탐지(스무딩 + 국소 극값)
   - 거래량 필터
   - **제안**: `buy_window`, `sell_window`, `confidence`, `rationale_tags[]`
5. UI: 당일 차트에 밴드·마커 오버레이 + 근거 카드.
6. Investor가 `제안으로 주문 채우기` → UC-002(수동 확인 후 주문).

## 대안

**A1 — 데이터 부족**

- 개장 직후: “표본 부족” + REST 폴링 갱신 버튼.

**A2 — 사용자 임계값**

- 민감도 슬라이더 → 피크 탐지 파라미터 변경.

## 산출 데이터 (학습 연계)

- 제안 스냅샷을 Tier3 `daytrade_suggestion` 이벤트로 저장(수락/거부 라벨).

## 비기능

- 분석 주기: 사용자 트리거 + 1분 자동(설정); API 한도 준수
- 제안은 **투자 자문 아님** 면책

## 도메인

- `IntradayPatternAnalyzer`, `SuggestionPresenter`
