# UC-003 — 현황·시세·차트 조회


| 항목 | 내용 |
|------|------|
| TraceID | UC-003 |

| 우선순위 | P0 |
| 액터 | Investor, KIS, DataProvider |

## 목적

계좌·시장 맥락·종목 시세·차트를 HTS 유사 탭에서 조회하고 주문 탭으로 맥락을 전달한다.

## 기본 흐름

1. **현황**: 잔고·보유·KPI·지수/환율(폴링) 표시 — Tier A + External 배지.
2. **시세**: 종목 검색 → REST 현재가·등락·거래량 테이블.
3. **차트**: Tier C OHLC + 기간 토글; 출처·지연 문구 고정.
4. Investor가 `주문에 반영` → UC-002로 심볼·가격 전달.

## 대안

- WebSocket(Tier B) 연결 시: 시세 폴링 주기 단축; 미연결 시 REST 폴링 + “실시간 미연결” 카드.

## 비기능

- ASR-001; 전용 HTS 틱 보장 없음(면책)
- 장시간 REST는 비동기·상태바 피드백
