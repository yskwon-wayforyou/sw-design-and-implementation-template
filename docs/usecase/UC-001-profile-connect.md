# UC-001 — 프로필 연결 및 paper/live 전환

| 항목 | 내용 |
|------|------|
| TraceID | UC-001 |
| 우선순위 | P0 |
| 액터 | Investor, KIS |

## 목적

모의투자·실전 API 프로필을 안전하게 선택·저장·전환하고 KIS에 인증된 세션을 확립한다.

## 사전 조건

- 사용자가 KIS 개발자 포털에서 앱키·시크릿·(실전) 계좌를 발급받았다.
- 로컬 볼트 키(`AST_KIS_VAULT_KEY`) 또는 최초 설정 마법사 완료.

## 사후 조건

- 활성 `KisProfile` (`paper` | `live`) 이 메모리·설정에 반영된다.
- OAuth access token이 유효하거나 갱신된다.
- UI 배너가 프로필에 맞는 색·문구를 표시한다.

## 기본 흐름

1. Investor가 앱을 기동한다.
2. 시스템이 `gui_settings` 의 시작 프로필을 로드한다.
3. 시스템이 볼트에서 해당 프로필 자격을 복호화한다.
4. 시스템이 `KisProfile` 검증: `paper` + 실전 `base_url` → **실패 종료**.
5. 시스템이 `AccessTokenManager` 로 토큰 발급.
6. 시스템이 연결 테스트(잔고 또는 시세 1회)로 세션 확인.
7. 상태바에 프로필·연결 상태 표시.

## 대안 흐름

**A1 — 프로필 전환 (실행 중)**

1. Investor가 메뉴 `환경 → 프로필 전환` 선택.
2. 시스템이 미체결·진행 중 주문 확인; 있으면 경고.
3. `live` 선택 시: 경고 대화상자 + 배너 프리뷰.
4. 세션 종료 → 새 프로필 로드 → 토큰 재발급.

**A2 — 토큰 만료**

1. API 401 수신.
2. 시스템이 1회 토큰 재발급·재시도.
3. 실패 시 Investor에게 재연결 안내.

## 예외

| 조건 | 처리 |
|------|------|
| 볼트 키 없음 | 설정 대화상자; 주문 비활성 |
| `AST_DISABLE_LIVE=1` | live 선택 거부 |
| 네트워크 타임아웃 | 상태바 오류; 재시도 버튼 |

## 비기능

- ASR-002, NFR-01
- 전환 완료까지 UI 블로킹 ≤ 3s (토큰 제외 네트워크)
