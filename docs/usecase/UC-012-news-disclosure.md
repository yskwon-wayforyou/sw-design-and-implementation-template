# UC-012 — 뉴스·공시·시장 맥락


| 항목 | 내용 |

| 우선순위 | P2 |

## 목적

투자 판단 보조를 위해 뉴스·공시 링크·시장 브리핑을 제공한다(자동 매매 입력은 아님).

## 기본 흐름

1. `뉴스·공시` 탭: 종목 연관 헤드라인(플레이스홀더→RSS/DART 링크).
2. 외부 브라우저 열기; 앱 내 iframe은 정책에 따라 제한.
3. Tier External 배지.

## 비기능

- 저작권·스크래핑 약관 준수; 본문 저장 최소화
