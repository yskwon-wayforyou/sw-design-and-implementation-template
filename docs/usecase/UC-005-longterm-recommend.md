# UC-005 — 장기 투자 모드: 종목 추천


| 항목 | 내용 |
|------|------|
| TraceID | UC-005 |

| 모드 | `MODE_LONG` |
| 우선순위 | P1 |

## 목적

다원 정보(모멘텀·변동성·유동성·사용자 Tier3 선호·공시 링크)를 종합해 **장기 보유 후보** 종목을 랭킹·추천한다.

## 기본 흐름

1. Investor가 장기 모드 진입·투자 테마/위험 성향(보수·중립·공격) 선택.
2. `LongTermFeatureBuilder` 가 유니버스(코스피200 샘플 또는 관심풀) 피처 계산.
3. `LongTermScorer` 가 점수·순위·요약 근거 생성.
4. UI: Top-N 카드 + “관심종목에 추가”.
5. (선택) 알림 스케줄(주 1회 리밸런스 제안).

## 대안

- 외부 재무 데이터 미연동 시: Tier1 OHLCV + Tier3만으로 **기술·행동 혼합** 스코어; 한계 명시.

## 비기능

- 배치 계산은 UI 스레드 외 Worker
- 추천은 참고용; 주문은 UC-002
